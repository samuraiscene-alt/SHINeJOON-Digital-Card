# SHINeJOON QR Digital Card - V1 Demo

현재 포함된 기능
- 전화 / 문자 / 이메일 / Instagram
- vCard 연락처 저장
- 지도 보기
- 명함 공유
- About Me / Gallery UI
- 카카오톡 / 홈페이지 / YouTube / TikTok / Facebook 자리
- QR 표시 자리
- 관리자 데모(localStorage)

실제 운영 전에 필요한 연결
1. GitHub Pages 배포 주소 확정
2. 실제 QR 생성
3. Supabase 프로젝트 연결 (Auth / Database / Storage)
4. 카카오톡 오픈채팅 또는 채널 URL
5. About Me 문구
6. 선택 SNS / 홈페이지 URL
7. 갤러리 추가 사진
